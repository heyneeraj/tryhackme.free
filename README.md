📌 About
This repository is a categorized TryHackMe room tracker maintained by Neeraj Rajeev. It brings together room links across offensive security, defensive security, infrastructure, application security, forensics, and general cybersecurity.
Use the Markdown checkboxes to record your progress:
`[ ]` — Not completed
`[x]` — Completed
The catalogue contains 728 room entries from the supplied source list. Room availability, free access, names, and URLs can change; check the official TryHackMe page before starting a room.
🎯 Objectives
Keep TryHackMe room links organized by cybersecurity domain.
Track completed and pending practical exercises.
Build consistent skills through hands-on labs.
Support learning in VAPT, web security, red teaming, SOC, DFIR, and more.
Maintain a simple progress checklist directly in GitHub.

✅ How to Use
Open a room using its TryHackMe link.
Complete the room on the TryHackMe platform.
Change its checkbox from `[ ]` to `[x]` in this README.
Commit and push your update to GitHub.
Revisit the tracker to continue your learning path.
Update your progress
```bash
git clone https://github.com/heyneeraj/tryhackme-free-rooms-tracker.git
cd tryhackme-free-rooms-tracker

# Edit README.md and mark completed rooms with [x]
git add README.md
git commit -m "Update TryHackMe room progress"
git push
```
> Replace the repository URL above if you use a different repository name.
